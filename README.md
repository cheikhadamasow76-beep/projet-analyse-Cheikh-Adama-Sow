# Projet 1 — Analyse des journaux d'un pare-feu

**Auteur : Cheikh Adama Sow

## Lancer le projet
```bash
pip install -r requirements.txt
python analyse.py
```
Le script lit `data/logs_reseau.csv`, nettoie les données, écrit `resultats.json`
et enregistre les figures dans `figures/`. L'analyse est décrite dans `rapport.md`.
